# Position Statement

## What This Is

1. **A research log** — documenting real experiments with multi-model resonance
2. **A hypothesis test** — can we detect coherence through cross-model agreement?
3. **An open notebook** — raw data, not polished conclusions
4. **A control primitive proposal** — silence as valid output state

## What This Is NOT

1. **NOT a finished product** — this is active research
2. **NOT a benchmark** — no leaderboards, no "best model"
3. **NOT about correctness** — we measure coherence, not truth
4. **NOT reinforcement learning** — no reward shaping, just gating
5. **NOT prompt engineering** — same prompt to all models, no optimization

## Core Principle

> If continuity cannot be guaranteed, no output is preferable to a wrong one.

## Research Questions

1. **Threshold calibration** — What coherence/drift values trigger silence optimally?
2. **Usability vs silence trade-off** — How much silence is acceptable?
3. **Orthogonality vs existing UQ methods** — Is this different from uncertainty quantification?
4. **Scalability + systematic bias** — Does this work at scale? Does it introduce bias?
