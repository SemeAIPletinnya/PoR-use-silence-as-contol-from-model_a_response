# Dialogues

Raw conversations with AI models, organized by date.

## Structure

Each experiment folder contains:
- `prompt.md` — The input prompt (same for all models)
- `model_a_response.md` — First model's response (e.g., ChatGPT)
- `model_b_response.md` — Second model's response (e.g., Grok)
- `notes.md` — Observations, ONLY facts, no interpretation

## Naming Convention

`YYYY-MM-DD-topic-name/`
